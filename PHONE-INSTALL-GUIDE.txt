ARETE PHONE PWA — DEPLOY & INSTALL

This folder is ready for HTTPS static hosting.

IPHONE INSTALL AFTER DEPLOYMENT
1. Open the HTTPS Arete URL in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Turn on Open as Web App if shown.
5. Tap Add.

GITHUB PAGES QUICK ROUTE
1. Create a GitHub repository.
2. Upload every file from this folder to the repository root.
3. Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main, /(root).
6. Save.
7. Open the Pages URL on iPhone Safari and Add to Home Screen.
